# User Account & Access Management System

This project is a backend-focused Django application built to manage user authentication and access control.
It includes user registration, login, logout, and protected views using Django's built-in authentication system.

## Features
- User registration and login
- Password hashing and authentication
- Protected routes
- Admin panel usage
- Clean backend structure

## Tech Stack
Python, Django, SQLite

## Purpose
Built as a learning-focused backend project emphasizing clean architecture and secure authentication logic.
